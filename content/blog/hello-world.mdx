## How this blog works

Each post is a Markdown/MDX file in `content/blog/` with frontmatter:

```md
---
title: "Post Title"
date: "YYYY-MM-DD"
excerpt: "One sentence summary shown on the blog list page."
tags: ["Tag One", "Tag Two"]
---
```

The rest of the file is rendered as the post body, and supports standard Markdown — headings, **bold**, _italics_, lists, links, and code blocks.

## Adding a new post

1. Create a new file at `content/blog/your-post-slug.mdx`.
2. Add frontmatter (title, date, excerpt, tags).
3. Write the post body below the frontmatter.

The post will automatically show up on `/blog`, sorted by date.
